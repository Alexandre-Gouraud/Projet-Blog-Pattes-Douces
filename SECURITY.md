# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No (please upgrade to the latest 1.0.x release) |

Security fixes are released as patch versions of the latest minor release.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately with GitHub
[Private Vulnerability Reporting](https://github.com/Alexandre-Gouraud/Projet-Blog-Pattes-Douces/security/advisories/new)
(tab **Security**, then **Report a vulnerability**). Include:

- the affected version or commit, and the component (API route, page, workflow…);
- the steps to reproduce, and the impact you observed;
- a suggested fix, if you have one.

## Response times (indicative)

| Step | Target |
|---|---|
| Acknowledgement | within 7 days |
| First assessment | within 14 days |
| Fix for a high or critical issue | within 30 days |

You will be kept informed of the progress and credited in the advisory if you
wish. Automated alerts (Dependabot, CodeQL, secret scanning, zizmor) are
reviewed on every release; see [CHANGELOG.md](CHANGELOG.md).

# Politique de sécurité

## Versions prises en charge

| Version | Prise en charge |
|---|---|
| 1.0.x | Oui |
| < 1.0 | Non (passez à la dernière version 1.0.x) |

Les correctifs de sécurité sont publiés en versions correctives de la dernière
version mineure.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir de ticket public** pour un problème de sécurité.

Signalez-le en privé avec le
[signalement privé de vulnérabilités](https://github.com/Alexandre-Gouraud/Projet-Blog-Pattes-Douces/security/advisories/new)
de GitHub (onglet **Security**, puis **Report a vulnerability**), en précisant :

- la version ou le commit concerné, et le composant (route d'API, page, workflow…) ;
- les étapes pour reproduire et l'impact constaté ;
- un correctif proposé, si vous en avez un.

## Délais de réponse (indicatifs)

| Étape | Délai visé |
|---|---|
| Accusé de réception | sous 7 jours |
| Première analyse | sous 14 jours |
| Correctif d'un problème élevé ou critique | sous 30 jours |

Vous serez tenu informé de l'avancement et cité dans l'avis si vous le
souhaitez. Les alertes automatiques (Dependabot, CodeQL, secret scanning,
zizmor) sont revues à chaque version ; voir [CHANGELOG.md](CHANGELOG.md).
